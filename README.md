# Minnu

> **An AI Powered GitHub-based Recruiter Engine**  
> *"Cracked engineers are not on LinkedIn"*

Minnu allows recruiters and engineering hiring managers to source software engineers based on real live GitHub activity, authentic GraphQL contribution heatmaps, verified commit velocities, and starred repositories.

---

## ⚡ Quickstart

```bash
# 1. Install dependencies
npm install

# 2. Start the local server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

## 🛠️ Tech Stack

- **Next.js 16** (App Router & Turbopack)
- **TypeScript 5**
- **Tailwind CSS v4** & Vanilla CSS Tokens
- **Instrument Serif** & Plus Jakarta Sans typography
- **Clerk Authentication** (`@clerk/nextjs`)
- **GitHub REST API v3 & GraphQL API v4**
